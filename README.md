# java-racingcar-precourse

## 기능 목록

### ⌨️ 입력 기능
-   `"경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)"` 안내 문구를 출력한다.
-   사용자가 쉼표(`,`)로 구분한 자동차 이름 문자열을 입력받는다.
-   `"시도할 횟수는 몇 회인가요?"` 안내 문구를 출력한다.
-   사용자가 시도할 횟수(숫자)를 입력받는다.

### ⚙️ 핵심 기능
-   입력받은 자동차 이름 문자열을 쉼표(`,`) 기준으로 분리하여 각 `Car` 객체를 생성한다.
-   개별 자동차 이름이 5자를 초과하는지 검증한다.
-   개별 자동차 이름이 공백이거나 비어있는지 검증한다.
-   개별 자동차 이름이 영문자로만 구성되어 있는지 검증한다.
-   자동차 이름 목록에 중복된 이름이 있는지 검증한다.
-   시도 횟수가 숫자인지 검증한다.
-   시도 횟수가 1 이상의 양의 정수인지 검증한다.
-   각 차수별로 모든 자동차에 대해 0에서 9 사이의 무작위 값을 생성한다.
-   무작위 값이 4 이상일 경우, 해당 자동차를 한 칸 전진(`-`)시킨다.
-   모든 시도가 끝난 후, 가장 멀리 이동한 자동차를 우승자로 선정한다.
-   우승자가 여러 명일 경우, 쉼표(`,`)로 구분하여 모두 표시한다.

### 🖥️ 출력 기능
-   `실행 결과` 문구를 출력한다.
-   각 차수의 실행 결과를 형식에 맞게 출력한다. (예: `pobi : --`)
-   모든 차수 실행 후, 최종 우승자를 형식에 맞게 출력한다. (예: `최종 우승자 : pobi, jun`)

---

## ⚠️ 예외 처리
-   모든 예외 상황 시 `IllegalArgumentException`을 발생시키고 애플리케이션을 종료한다.
-   자동차 이름이 5자를 초과하는 경우
-   자동차 이름에 공백이 포함되거나, 비어있는 이름이 있는 경우
-   자동차 이름에 영문자 이외의 문자가 포함된 경우
-   자동차 이름이 중복된 경우
-   시도 횟수가 숫자가 아닌 경우
-   시도 횟수가 1 미만의 정수(0 또는 음수)인 경우
